The purpose of this folder is to test whether a clear-versus-cloudy water-IoU gap measures cloud or a difference in what the tiles contain. On the released ml4floods WF2_unetv2_all checkpoint, an unmatched gap of 39.3 points is not a cloud cost. A citable cloud-robustness number must name its composition control, its same-tile control, and its aggregator.

A new model, including one suggested elsewhere, is useful only if it is scored with those three controls. It does not replace the non-cloud paste, the permanent-versus-flood split, or the Prithvi Sen1Floods11 run. The paste is a constructed fill on clear tiles, scored on unpainted pixels. It is not natural cloud. Write new JSON only under results/.

## How two helpers split the work

The audit side owns the three controls and will not accept a new model unless it is scored with the composition control, the same-tile control, and the aggregator. A model idea from elsewhere is a candidate checkpoint only. New JSON goes in results/.
